## Current Project

### NALIDE

**NALIDE** is a secure billing and provisioning system for resellers who sell and manage domains, SSL certificates and VPS services.

It is designed around:

- A protected Go core
- Plugin-based upstream integrations
- Automated security patrol and verification
- License verification and anti-tamper design
- A modern, themeable customer experience
